# Local headline fonts

Nunito, weights 800 and 900, Latin subset. Source: the unmodified WOFF2 files from `@fontsource/nunito@5.3.0` on the official npm registry. Project: https://github.com/googlefonts/nunito. Distributed under the SIL Open Font License 1.1; see `NUNITO-LICENSE.txt`.

Fonts are served by CareCard itself. Rendering the interface makes no requests to Google Fonts or a font CDN. Headings fall back to the installed rounded/system sans-serif stack while loading or if unavailable. Body copy and inputs retain the user's system sans-serif.
